# Pemetaan Barz ke Modul Praktikum

- **Modul 0:** Node.js/npm, XAMPP Apache/MySQL, Composer, Postman dan `htdocs`.
- **Modul 1:** Tailwind CSS v4 utility-first di elemen PHP/HTML; sumber `src/css/tailwind.css`, build CLI ke `assets/css/tailwind.css`.
- **Modul 2:** DOM, event handling, async/await, `fetch`, JSON, REST request, penanganan error dan Postman Collection.
- **Modul 3:** konsep PHP OOP diterapkan pada Laravel models, controllers, middleware dan resources; halaman PHP lama tidak ditulis ulang untuk menjaga kompatibilitas.
- **Modul 4:** Laravel 12 API, MySQL, migrations yang tidak membuat ulang tabel lama, Eloquent relationships, Resources, validasi dan CRUD.
- **Modul 5:** JWT Bearer Token, role middleware (`customer`, `admin`, `super_admin`), CORS serta upload gambar layanan yang divalidasi dan disimpan ke public disk.
- **Modul 6:** `assets/js/api.js` mengintegrasikan API dengan frontend menggunakan `fetch`, token sessionStorage, state loading sederhana, error validasi HTTP 422 dan fallback bila API tidak berjalan.

Desain, domain, dan alur bisnis Barz dipertahankan. Referensi modul dipakai untuk menyamakan tools dan pola teknik, bukan untuk menyalin proyek FlipPlay.
